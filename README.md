# claude-mods

Danny's Claude Code mods, published as the `danny-mods` plugin marketplace.

## Plugins

- **[quiet-output](quiet-output/)** — condensed transcript: each batch of tool
  calls folds into one dim `✓ N tools used` line, with `/quiet` and an
  instant band toggle to bring full detail back.

## Install

From a terminal Claude Code session:

```
/plugin install quiet-output --marketplace dyoung418/claude-mods
```

Answer `y` to add the marketplace, then pick the user scope.
